현재 버전

사용 도움말

  • 영역 (Ctrl+Alt+1): 화면이 멈추면 드래그로 영역을 고릅니다. Esc로 취소합니다.
  • 창: 열린 창 목록에서 캡처할 창을 고릅니다.
  • 전체 화면 (Ctrl+Alt+2): 마우스가 있는 모니터 전체를 캡처합니다.
  • 스크롤 (Ctrl+Alt+3): 스크롤되는 부분만 드래그하면 자동으로 내려가며 한 장으로 이어 붙입니다.
  • 지연: 3/5/10초 뒤에 캡처합니다. 자동 복사를 켜면 캡처 직후 클립보드에 복사됩니다.
  • 에셋 목록: 클릭=미리보기, 더블클릭=복사, 끌어서 다른 앱에 놓기, Delete=삭제.
  • 확대·축소: 미리보기 위에서 Ctrl+마우스 휠. 이미지 클릭 또는 맞춤/100% 버튼으로 되돌립니다.
  • 편집: 사각틀(R) · 원형틀(O) · 선/밑줄(L) · 화살표(A) · 문자(T) · 자르기(C, Enter로 적용). Shift=정비율/각도 고정, Ctrl+Z/Y=취소/다시. 저장하면 새 에셋으로 추가됩니다.
  • 에셋 저장 위치: 설정의 저장 폴더에서 확인·변경
