캡처를 시작해 보세요

위의 버튼이나 단축키로 캡처하면 오른쪽 에셋 목록에 쌓입니다.

캡처하면 미리보기 위쪽의 ✎ 편집 버튼으로 사각틀·원·화살표·문자·자르기를 넣을 수 있어요.

Ctrl+Alt+1 영역   Ctrl+Alt+2 전체 화면   Ctrl+Alt+3 스크롤

에셋0
클릭: 미리보기 · 더블클릭: 복사 · 끌어서 다른 앱에 놓기

설정

저장 폴더

캡처한 이미지가 저장되는 위치입니다. 한 번 지정하면 다시 바꾸기 전까지 유지됩니다.

폴더를 바꾸면 기존 캡처도 새 폴더로 옮겨집니다.

업데이트

현재 버전

사용 도움말

항목을 누르면 설명이 펼쳐집니다.

화면이 멈추면 드래그로 캡처할 영역을 고릅니다. Esc로 취소합니다.
열려 있는 창 목록(썸네일)에서 캡처할 창을 고릅니다.
마우스가 있는 모니터 전체를 캡처합니다.
스크롤되는 부분만 드래그하면 자동으로 내려가며 한 장으로 이어 붙입니다. 고정 헤더·사이드바는 빼고 선택하면 결과가 깔끔합니다.
지연을 3/5/10초로 두면 그 시간 뒤에 캡처합니다. ‘캡처 후 자동 복사’를 켜면 캡처 직후 클립보드에 복사됩니다.
클릭=미리보기, 더블클릭=복사, 끌어서 카톡·문서·폴더에 바로 놓기, Delete=삭제, Ctrl+C=복사. 이름은 미리보기 위쪽에서 바꿀 수 있습니다.
미리보기 위에서 Ctrl+마우스 휠로 확대·축소합니다. 이미지를 클릭하거나 맞춤/100% 버튼을 누르면 되돌아갑니다.
에셋을 선택하고 편집 버튼을 누릅니다. 선택(V) · 사각틀(R) · 원형틀(O) · 선/밑줄(L) · 화살표(A) · 문자(T) · 자르기(C, Enter로 적용). 선택 도구로 그린 주석을 눌러 옮기고, Delete로 지우고, 위쪽 색·굵기·글자 크기를 바꿀 수 있습니다. 문자는 ‘글자 배경’을 켜면 색 박스가 깔립니다. Shift=정비율/각도 고정, Ctrl+Z/Y=취소/다시. 저장하면 새 에셋으로 추가되고 원본은 그대로 남습니다.
