캡처하고, 꾸미고,
글자까지 복사

스크린샷 한 장 정리하려고 앱 여러 개 열지 마세요. 캡처부터 모자이크, 한국어 글자 인식, 화면 고정까지 CaptureBox 하나로 끝납니다.

Windows용 다운로드설치 파일 받기 GitHub에서 보기

처음 설치할 때 Windows SmartScreen 경고가 뜰 수 있어요 (코드 서명 없음). 추가 정보 → 실행을 누르시면 됩니다.

기능

캡처 앱 하나에 필요한 건 다 넣었어요

찍는 순간보다 찍은 뒤가 더 번거롭죠. 꾸미고, 가리고, 읽고, 고정하는 과정을 한 앱 안에서 끝냅니다.

캡처 4종

영역·창·전체 화면·스크롤. 단축키 Ctrl+Alt+1 2 3으로 바로 찍고, 키는 설정에서 바꿀 수 있어요.

스크롤 캡처

긴 페이지를 자동으로 스크롤하면서 한 장으로 이어 붙여요. 회의 자료, 긴 대화, 보고서에 좋아요.

바로 꾸미기

사각틀·원·화살표·번호·형광펜·글자·자르기. 편집본은 새 파일로 저장되고 원본은 그대로 남아요.

모자이크·블러

이름, 번호, 계좌 같은 개인정보를 공유하기 전에 한 번에 가려요.

글자 인식(OCR)

이미지 속 글자를 읽어 클립보드로 복사해요. 한국어 정밀 모델이 들어 있어 인터넷 없이 동작합니다.

화면에 고정

캡처를 작은 창으로 모든 창 위에 띄워 두세요. 끌어서 이동, Ctrl+휠 크기, Alt+휠 투명도.

클립보드·인쇄

‘캡처 시 대시보드 열지 않음’으로 바로 붙여넣기. Ctrl+P 인쇄 미리보기에서 용지·방향·여백도 고를 수 있어요.

늘 대기 · 자동 업데이트

창을 닫아도 트레이에서 대기해요. 윈도우 시작 시 자동 실행(선택)과 새 버전 알림·재설치까지 지원합니다.

화면 둘러보기

이렇게 써요

카드를 누르면 크게 볼 수 있어요. 화면 속 이름·번호는 모두 예시용 가짜 데이터입니다.

글자 인식

한국어를 제대로 읽어요

PaddleOCR PP-OCRv5 한국어 모델이 앱 안에 들어 있어요. 작은 글자와 한글에서 Windows 내장 OCR보다 훨씬 정확합니다.

  • 오프라인으로 동작해요. 이미지가 PC 밖으로 나가지 않아요.
  • 줄바꿈이 유지돼서 붙여넣기 좋아요.
  • 정밀 모드를 쓸 수 없으면 Windows 내장 OCR로 자동 대체돼요.
CaptureBox 정밀 모드0.5%
Windows 내장 OCR6.9%
Tesseract (한국어+영어)7.6%

글자 오류율 (낮을수록 좋음). 화면 캡처 같은 합성 이미지 60줄(글꼴·크기·배경 10종)로 잰 자체 시험 결과예요. 실제 이미지에서는 달라질 수 있고, 띄어쓰기는 가끔 빠질 수 있어요.

설치

1분이면 시작해요

관리자 권한이 필요 없고, 설치하면 바로 실행돼요.

설치 파일 받기

아래 버튼으로 CaptureBox-Setup-x.x.x.exe를 내려받아요.

실행하기

SmartScreen 경고가 뜨면 추가 정보 → 실행을 눌러요. 코드 서명이 아직 없어서 나오는 경고예요.

단축키로 캡처

Ctrl+Alt+1로 영역 캡처! 이후 업데이트는 앱이 알아서 알려줘요.

궁금한 점

정말 무료인가요?

네, 무료이고 MIT 라이선스 오픈소스예요. 코드는 GitHub에서 볼 수 있어요.

어떤 운영체제에서 쓸 수 있나요?

Windows 10/11 전용이에요. 맥과 리눅스, 모바일은 지원하지 않아요.

내 캡처가 서버로 전송되나요?

아니요. 캡처·편집·글자 인식은 모두 내 PC 안에서 처리돼요. 인터넷은 새 버전을 확인하는 데만 써요.

설치할 때 경고가 떠요

아직 코드 서명 인증서를 쓰지 않아서 Windows SmartScreen이 경고를 보여줘요. 추가 정보 → 실행을 누르면 됩니다.

캡처한 파일은 어디에 저장되나요?

기본은 사진\Screenshots 폴더예요. 설정에서 원하는 폴더로 바꾸면 그 위치가 계속 유지돼요.

스크롤 캡처가 잘 안 되는 화면이 있나요?

고정 헤더나 사이드바는 빼고 스크롤되는 부분만 선택하면 결과가 깔끔해요. 영상·애니메이션 영역이나 무한 스크롤 페이지는 정확도가 떨어질 수 있어요.

버그나 아이디어는 어디에 남기나요?
