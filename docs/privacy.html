CaptureBox 개인정보처리방침

시행일: 2026년 11월 8일 · 개발자: Lebi_Cybereun (GitHub: cybereun)

요약
CaptureBox는 사용자가 캡처 또는 OCR을 실행할 때 화면과 이미지에 접근합니다. 캡처 화면이나 OCR 결과에는 개인정보가 포함될 수 있습니다. Microsoft Store 버전은 이 데이터를 PC 안에서 처리하며 앱 서버로 전송하지 않습니다.

1. 접근하는 정보와 목적

  • 사용자가 캡처를 시작하면 선택한 영역·창 또는 화면의 이미지에 접근합니다. 이미지에는 이름, 연락처, 문서 내용 등 사람을 알아볼 수 있는 정보가 들어 있을 수 있습니다.
  • 사용자가 OCR을 실행하면 보관함의 이미지 내용을 읽어 글자로 변환합니다. 변환된 글자에도 개인정보가 포함될 수 있습니다.
  • 이 정보는 캡처, 자르기·주석·모자이크·블러 편집, OCR, 화면 고정, 인쇄와 파일 저장 기능을 제공하기 위해 사용됩니다. 앱은 개인정보를 자동으로 식별하거나 분류하지 않습니다.
  • 앱은 계정, 광고, 분석·사용 통계, 원격 오류 보고 기능을 제공하지 않습니다.

2. 로컬 저장과 클립보드

  • 캡처 이미지, 미리보기 이미지, 보관함 색인과 앱 설정은 AES-256-GCM으로 암호화해 PC에 저장합니다. 캡처 폴더는 사진\Screenshots가 기본이며 설정에서 바꿀 수 있습니다. 앱 설정은 앱 데이터 폴더에 암호화해 저장합니다.
  • 암호화 키와 현재 캡처 폴더 정보는 Windows 사용자 계정의 DPAPI로 보호해 `%LOCALAPPDATA%\CaptureBox`에 보관합니다. Store와 GitHub 설치 버전은 이 키와 폴더 정보를 공유합니다.
  • 암호화 키는 Windows 사용자 프로필에 묶입니다. 프로필을 초기화하거나 `%LOCALAPPDATA%\CaptureBox`의 키·상태 파일을 삭제하거나 다른 PC로 프로필을 옮기면 기존 보관함을 복호화하지 못할 수 있습니다. 이런 변경 전에 중요한 캡처를 일반 이미지 파일로 내보내 두세요.
  • OCR 중 만든 임시 이미지 파일은 처리가 끝난 뒤 삭제하고, 앱이 비정상 종료해 남은 임시 파일은 다음 실행 때 정리합니다. 파일 끌어 놓기와 탐색기에서 표시할 때는 기능 호환을 위해 앱 데이터의 CaptureBox 임시 폴더에 일반 PNG를 만듭니다. 앱이 종료될 때 삭제하고 다음 실행 때 남은 파일도 정리합니다. 파일 끌어 놓기가 끝난 순간을 Windows에서 알 수 없어 앱이 실행 중인 동안에는 임시 파일이 남습니다.
  • 캡처 후 자동 복사는 기본으로 켜져 있어 캡처 이미지가 Windows 클립보드에 복사됩니다. 앱 설정에서 끌 수 있습니다. 클립보드 전용 모드를 켜면 캡처가 계속 클립보드에 복사됩니다.
  • OCR 결과는 인식 후 Windows 클립보드에 복사됩니다. 클립보드 내용은 Windows와 사용자가 실행하는 다른 앱의 동작에 따라 접근될 수 있습니다.
  • 앱은 캡처 파일이나 설정에 자동 만료 기간을 두지 않습니다. 사용자가 앱 보관함 또는 파일 탐색기에서 삭제할 때까지 PC에 남습니다.

3. 네트워크 사용

Microsoft Store 버전앱 기능은 외부 서버에 접속하지 않습니다. 설치 및 앱 업데이트는 Microsoft Store가 처리하며, 해당 서비스의 처리는 Microsoft의 개인정보처리방침을 따릅니다.
GitHub 설치 버전새 버전을 확인하고 업데이트를 받기 위해 GitHub 공개 릴리즈 서비스에 접속할 수 있습니다. 이때 IP 주소 등 일반적인 연결 정보가 GitHub에 전달될 수 있습니다. 캡처 이미지, OCR 결과, 앱 설정은 GitHub로 전송하지 않습니다.

4. 사용자가 공유할 때

앱 보관함 안의 암호화된 캡처를 사용자가 복사하면 클립보드에 일반 이미지가 놓입니다. 사용자가 PNG/JPEG 파일로 저장하거나 인쇄·붙여넣기·공유하면 복호화된 정보가 사용자가 선택한 Windows 기능, 프린터, 앱, 장치 또는 서비스로 전달될 수 있습니다. 이러한 출력 파일과 클립보드는 앱 보관함 암호화 대상이 아닙니다. 그 이후의 처리는 해당 서비스의 개인정보처리방침과 설정을 따릅니다. 민감한 정보가 포함된 화면을 공유하기 전에 내용을 확인해 주세요.

5. 보관과 보호

앱이 관리하는 이미지, 미리보기, 색인과 설정은 AES-256-GCM으로 암호화하고, 암호화 키와 캡처 폴더 정보는 Windows DPAPI로 보호합니다. 이는 앱을 실행하지 않을 때 다른 Windows 계정이나 암호화 키가 없는 상태에서 저장 파일을 읽기 어렵게 합니다. 로그인된 같은 Windows 계정에서 실행되는 악성 프로그램이나 앱이 이미 복호화한 순간의 데이터까지 보호하지는 않습니다. 삭제는 활성 파일을 제거하지만 저장 장치의 이전 블록이 포렌식 방식으로 복구되지 않는다고 보장하지 않습니다. 앱은 파일을 서버에 백업하지 않습니다.

6. 사용자가 행사할 수 있는 통제

  • 사용자는 캡처와 OCR을 직접 시작하고, 자동 복사 설정을 바꿀 수 있습니다.
  • 캡처 파일은 앱에서 삭제하거나 저장 폴더에서 직접 열람·수정·삭제할 수 있습니다. 앱을 삭제해도 사용자가 지정한 폴더의 캡처 파일이 자동 삭제된다고 보장하지 않습니다.
  • 개발자는 이 로컬 데이터에 원격으로 접근할 수 없습니다. 개발자에게 데이터 열람이나 삭제를 요청하더라도 PC에 있는 파일을 대신 확인하거나 삭제할 수 없으므로, 사용자가 직접 관리해야 합니다.

7. 권한 사용

  • 화면 접근: 사용자가 요청한 캡처를 수행합니다.
  • 전역 단축키: 창이 닫혀 트레이에 있을 때에도 사용자가 단축키로 캡처하도록 합니다.
  • 마우스 휠 입력: 사용자가 시작한 스크롤 캡처 중 선택 영역을 자동으로 스크롤합니다.
  • PowerShell: 앱에 포함된 입력 보조 및 Windows OCR 대체 스크립트를 실행합니다.
  • 파일 및 클립보드: 사용자가 캡처·복사·저장 기능을 이용할 때 이미지와 OCR 결과를 처리합니다.

8. 제3자 제공과 오픈소스 구성요소

Microsoft Store 버전에서 개발자는 캡처 이미지와 OCR 결과를 제3자에게 제공하지 않습니다. GitHub 설치 버전의 업데이트 확인에는 GitHub가 연결 서비스로 사용되며, 이때의 연결 정보 처리는 GitHub 정책을 따릅니다.

글자 인식에는 PaddleOCR PP-OCRv5 모델(Apache-2.0)과 ONNX Runtime(MIT)을 사용합니다. 자세한 내용은 오픈소스 고지에 있습니다.

9. 문의와 방침 변경

개인정보 처리방침 문의는 GitHub Issues로 남겨 주세요. 공개 이슈에는 캡처 이미지, OCR 결과 등 개인정보를 올리지 마세요. 방침이 바뀌면 이 페이지에 변경일과 함께 게시합니다.

Privacy Policy (English summary)

CaptureBox accesses the screen or an image when you start a capture or OCR operation. These images or OCR text may contain personal information. The Microsoft Store build processes them locally and does not send them to the developer or a server. App-managed captures, thumbnails, index, and settings are encrypted with AES-256-GCM. The key and active capture-folder pointer are protected with Windows DPAPI in `%LOCALAPPDATA%\CaptureBox`; the key is tied to the Windows user profile, so profile reset, key-file removal, or moving the profile may make the vault unreadable. Export important images before such changes. OCR temporary images are deleted after processing. Clipboard content, user-saved PNG/JPEG exports, printing, and temporary drag/reveal PNGs are ordinary decrypted output; drag/reveal files remain until the app exits and leftovers are cleared on next launch. The GitHub build may contact GitHub for updates and send ordinary connection data such as an IP address, but not captures, OCR text, or settings. Contact: GitHub Issues. Do not post personal information in public issues.
