CaptureBox 개인정보처리방침

시행일: 2026년 11월 8일 · 개발자: Lebi_Cybereun (GitHub: cybereun)

한 줄 요약
CaptureBox는 개인정보를 수집하지 않고, 캡처 이미지를 서버로 보내지 않습니다. 모든 처리는 내 PC 안에서 이루어집니다.

1. 수집하는 정보

없습니다. 계정 가입, 로그인, 광고, 사용 통계(분석), 오류 보고 전송이 모두 없습니다.

2. 이미지와 글자 처리

  • 캡처, 편집, 모자이크·블러, 글자 인식(OCR), 인쇄는 모두 내 PC 안에서만 처리됩니다.
  • 글자 인식 모델은 앱에 내장되어 있어 인터넷 연결이 필요 없습니다.
  • 캡처한 이미지는 사용자가 정한 폴더(기본: 사진\Screenshots)와 앱의 설정 폴더에 저장됩니다. 사용자가 직접 삭제할 수 있습니다.
  • 이미지를 클립보드에 복사하는 기능은 사용자가 캡처하거나 복사를 눌렀을 때만 동작합니다.

3. 네트워크 사용

Microsoft Store 버전앱이 직접 인터넷에 접속하지 않습니다. 업데이트는 Microsoft Store가 처리합니다.
GitHub 설치 버전새 버전이 있는지 확인하기 위해 GitHub(github.com/cybereun/CaptureBox)의 공개 릴리즈 정보에 접속합니다. 이때 일반적인 접속 정보(IP 주소 등)가 GitHub에 전달될 수 있으며, 캡처 이미지나 사용자 정보는 전송되지 않습니다.

4. 앱이 사용하는 권한과 목적

  • 화면 캡처: 사용자가 캡처 단축키나 버튼을 눌렀을 때만 화면을 읽습니다.
  • 전역 단축키: 앱이 창 없이 트레이에 있어도 단축키로 캡처할 수 있도록 합니다.
  • 마우스 입력(휠): 스크롤 캡처를 하는 동안에만 선택한 영역에서 마우스 휠을 자동으로 돌립니다.
  • PowerShell 실행: 스크롤 캡처의 입력 도우미와 Windows 내장 OCR(대체 수단)에 쓰이며, 앱에 포함된 스크립트만 실행합니다.
  • 파일 쓰기: 캡처 이미지와 설정을 사용자가 정한 폴더에 저장합니다.

5. 제3자 제공

수집하는 정보가 없으므로 제3자에게 제공하는 정보도 없습니다.

6. 오픈소스 구성요소

글자 인식에는 PaddleOCR PP-OCRv5 모델(Apache-2.0)과 ONNX Runtime(MIT)을 사용합니다. 자세한 내용은 오픈소스 고지에 있습니다.

7. 변경과 문의

이 방침이 바뀌면 이 페이지에 시행일과 함께 게시합니다. 문의는 GitHub Issues로 남겨 주세요.

Privacy Policy (English summary)

CaptureBox does not collect personal data and does not upload your screenshots. Capture, editing, OCR and printing all run locally on your PC, and the OCR model is bundled with the app. The Microsoft Store version makes no network connections by itself; the GitHub-installed version contacts GitHub only to check for new releases. Contact: GitHub Issues.
