CaptureBox 개인정보 처리방침
시행일: 2026년 11월 8일
개발자: Lebi_Cybereun (GitHub: cybereun)

1. 접근하는 정보와 처리 목적
CaptureBox는 사용자가 캡처를 시작할 때 선택한 화면 영역·창 또는 화면 이미지에 접근합니다. 사용자가 보관된 이미지에 OCR을 실행하면 해당 이미지의 글자를 읽어 텍스트로 변환합니다. 화면과 OCR 결과에는 이름, 연락처, 문서 내용 등 사람을 알아볼 수 있는 정보가 포함될 수 있습니다. 앱은 이 정보를 캡처, 편집(자르기·주석·모자이크·블러), OCR, 화면 고정, 인쇄와 파일 저장 기능을 제공하기 위해 처리합니다. 앱은 개인정보를 자동으로 식별하거나 분류하지 않습니다.

2. 로컬 저장과 암호화
앱이 관리하는 캡처 이미지, 미리보기 이미지, 보관함 색인과 앱 설정은 AES-256-GCM으로 암호화해 PC에 저장합니다. 캡처 폴더는 사진\Screenshots가 기본이며 설정에서 사용자가 바꿀 수 있습니다. 앱 설정은 CaptureBox 앱 데이터 폴더에 암호화해 저장합니다.

암호화 키와 현재 캡처 폴더 정보는 Windows DPAPI로 보호해 %LOCALAPPDATA%\CaptureBox에 보관합니다. Store와 GitHub 설치 버전은 이 키와 폴더 정보를 공유합니다. 키는 Windows 사용자 프로필에 묶입니다. 사용자 프로필을 초기화하거나 %LOCALAPPDATA%\CaptureBox의 키·상태 파일을 삭제하거나 다른 PC로 프로필을 옮기면 기존 보관함을 복호화하지 못할 수 있습니다. 이런 변경 전에 중요한 캡처를 일반 이미지 파일로 내보내 두세요.

OCR 처리용 임시 이미지 파일은 처리가 끝난 뒤 삭제합니다. 파일 끌어 놓기와 탐색기에서 표시할 때는 기능 호환을 위해 CaptureBox 앱 데이터의 임시 폴더에 일반 PNG를 만듭니다. 앱이 종료될 때 삭제하고 다음 실행 때 남은 파일도 정리합니다. Windows에서 파일 끌어 놓기가 끝난 순간을 알 수 없어 앱이 실행 중인 동안에는 임시 파일이 남습니다.

3. 클립보드, 저장, 인쇄와 공유
캡처 후 자동 복사는 기본으로 켜져 있어 캡처 이미지가 Windows 클립보드에 복사됩니다. 설정에서 자동 복사를 끌 수 있습니다. 클립보드 전용 모드에서는 캡처가 클립보드에 복사됩니다. OCR 결과도 OCR 실행 후 Windows 클립보드에 복사됩니다. 클립보드 내용은 Windows와 사용자가 실행하는 다른 앱의 동작에 따라 접근될 수 있습니다.

사용자가 PNG/JPEG 파일로 저장하거나 클립보드에서 붙여넣거나 인쇄·공유하면 복호화된 정보가 사용자가 선택한 Windows 기능, 프린터, 앱, 장치 또는 서비스로 전달될 수 있습니다. 이러한 출력 파일과 클립보드는 앱 보관함 암호화 대상이 아닙니다. 이후 처리는 해당 서비스의 개인정보처리방침과 설정을 따릅니다. 민감한 정보를 공유하기 전에 내용을 확인해 주세요.

4. 네트워크와 제3자 제공
Microsoft Store 버전은 앱 기능을 위해 외부 서버에 접속하지 않으며, 캡처 이미지, OCR 결과 또는 앱 설정을 개발자나 서버로 전송하지 않습니다. 설치와 앱 업데이트는 Microsoft Store가 처리하며, 해당 서비스의 개인정보 처리는 Microsoft 정책을 따릅니다.

GitHub 설치 버전은 새 버전을 확인하고 업데이트를 받기 위해 GitHub 공개 릴리즈 서비스에 접속할 수 있습니다. 이때 IP 주소 등 일반적인 연결 정보가 GitHub에 전달될 수 있습니다. 캡처 이미지, OCR 결과와 앱 설정은 GitHub로 전송하지 않습니다.

5. 보관과 보호
AES-256-GCM 암호화는 앱이 관리하는 로컬 파일에 적용하고, 암호화 키와 캡처 폴더 정보는 Windows DPAPI로 보호합니다. 이는 앱을 실행하지 않을 때 다른 Windows 계정이나 암호화 키가 없는 상태에서 저장 파일을 읽기 어렵게 합니다. 로그인된 같은 Windows 계정에서 실행되는 악성 프로그램이나 앱이 이미 복호화한 순간의 데이터까지 보호하지는 않습니다. 파일 삭제는 활성 파일을 제거하지만 저장 장치의 이전 데이터 블록이 포렌식 방식으로 복구되지 않는다고 보장하지 않습니다. 앱은 파일을 서버에 백업하지 않으며 자동 만료 기간을 두지 않습니다.

6. 사용자의 통제와 문의
사용자는 캡처와 OCR을 직접 시작하고 자동 복사 설정을 변경할 수 있습니다. 캡처 파일은 앱에서 삭제하거나 저장 폴더에서 직접 열람·수정·삭제할 수 있습니다. 앱을 삭제해도 사용자가 지정한 폴더의 캡처 파일이 자동 삭제된다고 보장하지 않습니다. 로컬 데이터는 개발자에게 전송되지 않으므로 개발자가 원격으로 열람·수정·삭제할 수 없습니다. 개인정보 처리방침 문의는 https://github.com/cybereun/CaptureBox/issues 에 남겨 주세요. 공개 이슈에는 캡처 이미지, OCR 결과 등 개인정보를 올리지 마세요.

7. 기타
앱은 계정, 광고, 분석·사용 통계 또는 원격 오류 보고 기능을 제공하지 않습니다. 글자 인식에는 앱에 포함된 PaddleOCR PP-OCRv5 모델과 ONNX Runtime을 사용합니다. 방침이 바뀌면 이 문서와 개인정보처리방침 페이지에 변경일과 함께 게시합니다.

Privacy Policy (English summary)
CaptureBox accesses the screen or an image when you start a capture or OCR operation. Images and OCR text may contain personal information. The Microsoft Store build processes them locally and does not send them to the developer or a server. App-managed captures, thumbnails, index, and settings are encrypted at rest with AES-256-GCM. The key and active capture-folder pointer are protected with Windows DPAPI in %LOCALAPPDATA%\CaptureBox and shared by the Store and GitHub builds. The key is tied to the Windows user profile; a profile reset, removal of the key/state files, or moving the profile may make the vault unreadable. Export important images before such changes. OCR temporary images are deleted after processing; any temporary files left by an abnormal exit are cleared on next launch. Clipboard content, user-saved PNG/JPEG exports, printing, and temporary drag/reveal PNGs are ordinary decrypted output and are not encrypted by the app. Drag/reveal files remain until the app exits and leftovers are cleared at next launch. The GitHub build may contact GitHub for updates and send ordinary connection data such as an IP address, but not captures, OCR text, or settings. The app does not use accounts, ads, analytics, telemetry, or remote crash reporting. Contact: https://github.com/cybereun/CaptureBox/issues. Do not post personal information in public issues.
